# Warrior Leaders: logo guide

The judging, leaderboard and big-screen app for Northern Warrior Competitions.

## The idea
A **W that climbs** (each peak higher than the last, like a team moving up the board) and a **gold L** leaning forward beside it like a sprint finish. Every stroke leans at the same 75° and shares one stroke width.

## Versions (in `svg/`, PNGs in `png/`)
| File | Use |
|---|---|
| `lockup-horizontal-*` | **Main logo.** Mark + WARRIOR / LEADERS. Headers, screens, print. |
| `lockup-stacked-*` | Square-ish spaces: lanyards, posters, social posts, T-shirt backs. |
| `symbol-*` | The WL mark alone: app icon, avatars, merch, where the name is already nearby. |
| `symbol-small-*` | **32 px and below** (wider W–L gap so the letters don't merge). |
| `wordmark-*` | Name only, when the mark is used elsewhere on the same piece. |

Colourways for each: `colour` (black + gold, light backgrounds) · `reversed` (white + gold, dark backgrounds) · `black` · `white` · `gold` (single-colour print, embroidery, vinyl).

Web icons are in `web/` (favicon.ico/svg, apple-touch-icon, 192/512 + maskable, `site.webmanifest`, `head-snippet.html`).

## Colour
| | HEX | RGB | CMYK (approx.) | Use |
|---|---|---|---|---|
| **Leader Gold** | `#aa8601` | 170 134 1 | 0 21 99 33 | The L, "LEADERS" |
| **Warrior Black** | `#0a0a0a` | 10 10 10 | 0 0 0 96 | The W, "WARRIOR", backgrounds |
| White | `#ffffff` | 255 255 255 | 0 0 0 0 | The W and "WARRIOR" on dark |

- Pantone: no exact match. Check **7557 C** and **125 C** against a swatch book before ordering print.
- Contrast: gold on black **5.8 : 1** (good for anything). Gold on white **3.4 : 1**: fine for the logo and large headings, **not for small body text**.
- Gold is the leader colour. Use it for the L, "LEADERS" and first-place highlights, not as a background wash.

## Type
**League Spartan** (SIL Open Font License, free for logos). The name in the logo is ExtraBold (800), already outlined in the SVGs, so no font is needed to use them. Use League Spartan 600–800 for headings next to the logo.

## Clear space
Keep a gap of at least **one stroke width** (the height of the L's foot) on all sides. Nothing else (text, edges, other logos) goes inside it.

## Minimum sizes
| Version | Screen | Print |
|---|---|---|
| Horizontal lockup | 120 px wide | 30 mm wide |
| Stacked lockup | 80 px wide | 20 mm wide |
| Symbol | 16 px (use `symbol-small` ≤ 32 px) | 6 mm |

## Backgrounds
- Light/white → `colour`. Black or dark photos → `reversed`.
- On gold → `black` only. On busy photos → put the logo on a black panel.

## Don't
- Recolour the W gold or the L another colour; swap the order to "LW".
- Change the lean, stretch, squash, outline or add shadows/glows/gradients.
- Re-set the name in another font, or bring back "THE".
- Put the colour version on dark backgrounds (the black W disappears).
- Use the full-size symbol below 32 px (use `symbol-small`).

## Notes
- Masters are generated by `kit-src/build_kit.py` (geometry + outlined League Spartan), so changes stay consistent across every file.
- Not trademark-checked. Run a search (UK IPO / EUIPO) before using it beyond the event.
